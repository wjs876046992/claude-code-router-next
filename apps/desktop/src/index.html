CCR DESKTOP · LOCAL CONNECTION

Your gateway stays yours.

Connecting to your local Claude Code Router. If the gateway is offline, this page remains available instead of a blank window.

Get connected

  1. Install Node.js and CCR separately, then run ccr start in your terminal.
  2. Check your local config.json and API key. The desktop reads CCR_CONFIG_DIR, CCR_DESKTOP_PORT and CCR_DESKTOP_API_KEY when supplied.
  3. Choose Refresh from the tray menu. Its status row reports connection and switch errors; the full Web UI opens after readiness.

An occupied or unresponsive port is never reclaimed. Closing this window hides it to the tray. “Quit Desktop” stops only the desktop — your gateway keeps running.

Configuration changes made after launch require relaunching the desktop (not the gateway). Consult apps/desktop/README.md for build and authentication details.
